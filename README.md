# College Student Portal

## Project Description
The College Student Portal is a simple multi-page website
created using HTML5 only.

## Project Pages
1. index.html - Home page
2. about.html - College information and facilities
3. timetable.html - Weekly class timetable
4. registration.html - Student registration form

## Technologies Used
- HTML5

## Features
- Navigation links between all four pages
- College introduction and announcements
- Courses and student facilities
- Weekly timetable using an HTML table
- Registration form with labels and validation
- Course dropdown and study mode radio buttons
- Interests checkboxes
- Submit and Reset buttons
- Semantic HTML elements

## Project Structure
- index.html
- about.html
- timetable.html
- registration.html
- README.md
- assets/images/college.jpg

## How to Run
1. Open the project folder.
2. Open index.html in a web browser.
3. Use the navigation links to visit the other pages.

## Testing
- Checked navigation links
- Checked page titles
- Tested form validation

- Checked the timetable

## Limitations
This is an HTML prototype.
It does not save registration data to a database.
